Assignment Description - Loops & Functions
This repository contains my solutions for Python Loops & Functions .The main goal of this assignment was to practice Python programming by solving different problems using loops, conditions, functions. The task starts with basic loop problems and gradually moves towards functions and small real-world applications.

How to Setup:
Download Python on your machine and any one of IDE.

Go inside the project folder:
cd super30-python-loops-functions-task

How to Run :
For example: python 01_number_analyzer.py
Some programs will ask for input while running, especially the menu-driven applications.

Completed Questions:
I have completed all 20 questions in the assignment:
Number Analyzer – Find even and odd numbers and analyze a range of numbers.
Multiplication Table – Generate the multiplication table for a given number.
Sum and Average – Calculate the sum and average of numbers without using the built-in sum() function.
Maximum and Minimum – Find the maximum and minimum values without using max() and min().
Character Frequency – Count how many times each character appears in a string.
Vowel, Consonant, Digit and Space Counter – Analyze the different types of characters in a sentence.
Prime Number Finder – Find prime numbers within a given range.
Pattern Generator – Create number patterns using nested loops.
Student Marks Analyzer – Analyze student marks and calculate results such as average, highest and lowest marks.
ATM Withdrawal Simulator – Simulate basic ATM operations such as checking balance, depositing and withdrawing money.
Password Retry System – Allow the user to enter a password with a limited number of attempts.
Number Guessing Game – Guess a randomly generated number with hints.
Menu-Driven Calculator – Perform basic mathematical operations through a menu.
Own Sum Function – Create a custom function to calculate the sum of numbers.
Reusable Number Analysis – Check whether a number is positive, negative, zero, even, odd, prime or non-prime.
Student Grade Calculator – Calculate a student's grade based on marks.
Shopping Cart – Add, remove and view items and calculate the total price.
Employee Salary Calculator – Calculate salary, bonus, tax and final salary.
Bank Account Mini Application – Perform basic banking operations and maintain transaction history.
Student Registration System – Add, view, search, update and delete student records and perform basic analysis.
